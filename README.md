# Máquina Virtual Didáctica (MV)

## Descripción

Máquina virtual educativa para la enseñanza de arquitectura de computadores y lenguaje ensamblador. Interpreta código ASM didáctico compilado a binario y simula una arquitectura completa con registros, memoria, pila y operaciones lógico-aritméticas.

## Características

- Intérprete de ASM didáctico (.vmx)
- 32 registros virtuales de 32 bits
- Memoria configurable (hasta 64KB)
- Soporte para entrada/salida interactiva
- Herramienta disassembler para análisis de código
- Ejemplos incluidos: listas enlazadas, árboles binarios, operaciones básicas
